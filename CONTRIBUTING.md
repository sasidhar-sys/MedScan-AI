# Contributing to MedScan AI

Thank you for your interest in contributing to **MedScan AI**!

## Guidelines
1. Fork the repository and create a feature branch (`feature/your-feature-name`).
2. Follow strict typing and standard code formats.
3. Ensure unit & integration tests pass before opening a Pull Request.
4. Update appropriate documentation for API or architectural changes.

## Code of Conduct
Please review and adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).
